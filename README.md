# MIMIC — 表情气象台

一个本地优先、无需后端的 AR 互动原型：微笑下雨，张嘴大笑触发烟花，烟花与跟随头部的屏幕空间椭圆碰撞体反弹。

## 运行

需要 Node.js 22.12 或更高版本。

```bash
npm ci
npm run dev
```

打开终端显示的 localhost 地址，点击“开启摄像头”并授权。首次加载后，单人正对镜头、保持自然表情约 2 秒完成校准。微笑触发雨幕；保持微笑并张嘴触发烟花。重新校准按钮可以重采个人基线。

```bash
npm test
npm run build
npm run preview
npm run test:e2e
```

若 Playwright 提示浏览器不存在，执行 `npx playwright install chromium` 后再运行端到端测试。

## 实现与成本边界

```text
getUserMedia → 480px ImageBitmap → 经典 Web Worker / MediaPipe Face Landmarker
                                      ↓ 关键点 + blendshape 系数
             镜像与 object-fit:cover 坐标变换 + 表情状态机
                                      ↓
             Canvas 2D / 有界粒子池 / 移动椭圆连续碰撞
```

- 真实摄像头入口使用 `getUserMedia`，只请求视频，不请求麦克风。
- MediaPipe `0.10.32`、同版本 WASM 及固定版本人脸模型均由本站提供；不依赖运行时第三方 CDN。
- 构建时下载 Google 官方模型，并核对 SHA-256：`64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`。
- CPU 推理放在 Worker，不把同步 `detectForVideo` 放进主线程动画循环；经典 Worker 避免 WASM 加载器的 `importScripts` 与模块 Worker 冲突。
- 模型只在摄像头授权并成功读取后才加载；打开页面、体验手动特效或拒绝权限，不请求模型、WASM 或推理 Worker。不能用约 20 KB 的业务 JS 冒充全部冷启动成本：SIMD 路径的页面、Worker、模型及 WASM 合计约 15.6 MB 未压缩；实际网络传输受服务器压缩与缓存影响。
- 推理最高约 12.5 Hz，节能档最高约 6.7 Hz，且间隔不少于上次推理耗时的 1.5 倍。**最多只有 1 帧在途**，不创建视频帧积压。
- 粒子上限 720；慢设备降至 360，DPR 从最多 1.75 降至 1。类型化数组粒子数据约 15.5 KiB，不含模型、Canvas 或浏览器内存。
- 物理步长 1/120 秒，每次动画回调最多补 4 步；后台暂停，避免恢复时追赶几千步。
- 使用相对头部运动的扫掠碰撞，按椭圆法线反射速度；粒子不互相碰撞，复杂度为 O(粒子数)。
- 表情系数时间平滑、进入/退出阈值滞回、持续时间门槛，以及 1.2 秒烟花冷却，减少抖动与重复爆炸。
- 校准超时明确提示使用原有阈值；不把模型系数称作“情绪概率”。

## 诚实的功能边界

1. **这是 2D 屏幕空间物理，不是 3D 头部扫描。** 碰撞体包含头部平移和面内旋转，但没有真实深度遮挡、头发网格或完整侧脸几何。
2. **“大笑”是可见表情代理。** 综合嘴角上扬、张嘴与脸颊动作，不识别声音，不能保证区分所有说话、夸张表情或真实情绪。
3. 单人体验；检测到两张人脸时暂停交互并提示。侧脸、遮挡和弱光会降低稳定性。
4. 无人脸时撤销碰撞体；超过 400 ms 的旧关键点不再使用。单帧处理超过 4 秒时停止计算和摄像头，显示错误。
5. “体验雨幕 / 体验烟花”是**显式标识的手动演示模式**，不能用来冒充摄像头表情验收。
6. 仅支持 HTTPS 或 localhost。手机端应直接打开 HTTPS 页；内置浏览器可能需要改用系统 Chrome / Safari。
7. 无录像、截图上传、服务器推理、广告追踪或持久化人脸数据。停止体验或离开页面会释放媒体轨道。网络请求用于获取站点资源，不携带视频帧。

## 验证

- 32 项单元测试：表情状态、误触发保护、冷却、镜像裁切、连续碰撞、移动头部动量、粒子上限、动态降级。
- 7 项浏览器测试：桌面与移动视口、真实模型初始化、浏览器模拟摄像头、无脸提示、轨道释放、权限拒绝且零模型请求、模型失败、低动态及性能采样。
- 一次桌面 Chromium 141 无头测试，1440×1000、DPR 1、持续烟花，219 个稳态帧：约 60 FPS，p95 动画帧间隔 16.7 ms，主线程更新/绘制代码耗时 p95 约 0.2 ms。
- 该数据不是最低端手机的性能承诺，也不是摄像头开启后的人脸推理性能。移动测试为视口模拟；**真人表情准确率、iOS/Android 真机、弱光与长时间温升尚待实测**。

端到端测试在新机器上可复现，性能数字可能随设备和负载变化。测试中的模拟摄像头不是开发者真实摄像头。

## 开发与部署

- `src/core/` 包含可单独测试的表情、坐标映射、碰撞和粒子逻辑。
- `src/vision.worker.ts` 是 Worker 源码。修改后重启 `npm run dev` 或执行 `npm run assets` 再刷新；Vite 的主界面热更新不会自动重建这个经典 Worker。
- `scripts/prepare-assets.mjs` 将 Worker 打包为 IIFE，并准备同源模型和 WASM。生成文件不提交到源码库。
- GitHub Actions 对主分支执行锁定依赖安装、测试、构建和 Pages 发布。其他静态平台直接部署 `dist/`。
- 第三方组件说明见 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。
- 本仓库不包含笔试题目图集、签名下载链接、用户视频、凭据或模型输出的个人记录。
