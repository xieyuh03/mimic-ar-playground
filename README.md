# MIMIC — 表情气象台 · v0.2

微笑下雨，大笑时雨停、烟花升空，烟花粒子与移动的头部碰撞。摄像头处理全部在浏览器本地进行。

**[在线体验](https://xieyuh03.github.io/mimic-ar-playground/)** · **[完整提交稿 PDF](./assignment/output/submission-v2.pdf)** · **[换电脑接着做](./CONTINUE.md)** · **[三轮迭代记录](./ITERATION-LOG.md)**

## 这一版修了什么

- **不是简单降低阈值。** 去掉脸颊系数的硬否决，引入真实嘴唇开度、当前笑容和短时笑容证据；大笑状态优先，雨幕和烟花互斥。
- 提供“大笑准备”进度、原始张嘴系数、嘴部几何状态，避免将 `jawOpen` 冒充“大笑概率”。
- 增加**大笑灵敏度**和**学习我的大笑**；参考仅在当前会话中使用，不持久化人脸信息。
- 推理Worker的请求地址带构建内容指纹，避免旧版10分钟静态缓存使新界面读到旧版几何协议。
- 雨幕分远、中、近三层，具备风向、运动拖影、接触水花与亮背景对比。
- 烟花包含升空尾焰、错峰爆炸、空间投影分布、四点曲线拖尾、渐隐光晕及头部碰撞反馈，而不是均匀彩色圆环。
- 修复切换时旧雨滴残留、退出烟花后火箭继续爆炸、短暂丢脸绕过冷却、全屏慢雨滴提前消失等问题。
- 将三部分报告、评分图集、PDF 构建工具及实测摘要一并放入仓库，方便换电脑继续。

## 怎么体验

1. 点击“开启摄像头”，允许权限。首次授权后才下载模型。
2. 保持自然表情约 2 秒；页面显示基线校准完成后开始体验。
3. 微笑 → 下雨。保持笑容并自然张嘴片刻 → 雨停、火箭升空、烟花绽放。
4. 若大笑不易触发，点“学习我的大笑”并保持该表情约 1.5 秒，或适度提高灵敏度。说话误触时反向调低。
5. 移动头部看粒子反弹；可勾选碰撞轮廓、放大画面。
6. 不开摄像头也能体验明确标识的**手动演示**。手动模式不是识别验收结果。

## 运行、测试与文档

需要 Node.js **22.12+**。

```bash
npm ci
npm run dev
```

```bash
npm test                 # 表情、几何、校准、物理、预算
npm run test:reports     # Ajv JSON Schema + 20图分数算式 + 200字复盘
npm run build           # 类型检查、同源模型/WASM、经典Worker、生产构建
npx playwright install chromium
npm run test:e2e         # 浏览器链路、真实模型、本地图片流和合成表情回归
```

性能采样需要先在另一个终端启动 `npm run preview`：

```bash
npm run test:performance # 三个场景，各30秒；含真实模型+模拟摄像头
npm run documents       # 从 assignment/ 重建完整HTML、Markdown和PDF
```

`npm run dev` 首次下载固定版本模型。首次运行端到端/PDF 工具若缺少浏览器，使用上面的 Playwright 安装命令。中文 PDF 依赖操作系统中文字体，可使用 Noto Sans CJK SC、苹方或微软雅黑。

## 架构与硬预算

```text
摄像头授权成功 → 同源模型与WASM → 480px视频帧
                                      ↓ 单帧在途
                              经典Worker / CPU推理
                                      ↓
                   blendshape系数 + 像素比例正确的嘴部几何
                                      ↓
          时间证据状态机 + 个人参考 + 镜像/cover坐标映射
                                      ↓
        有界Canvas粒子池 / 烟花队列 / 扫掠椭圆碰撞 / 渐隐拖尾
```

| 项目 | 上限 / 策略 |
|---|---|
| 模型 | MediaPipe Tasks Vision 0.10.32；SDK、WASM 同版本；模型校验和固定 |
| 推理 | 最多1帧在途；最高约12.5Hz，节能档约6.7Hz；耗时长时继续降频 |
| 粒子 | 正常720、节能360、低动态180；所有尾焰、水花和碰撞反馈计入同一上限 |
| 发射队列 | 最多6个槽；正常每次最多3发，节能/低动态1发；切换取消不兼容粒子 |
| DPR / 像素 | DPR≤1.75，节能≤1；Canvas backing pixels约250万上限 |
| 数值状态 | 粒子、4点拖尾及发射队列的所有类型化数组总计低于64KiB；光晕小图集复用 |
| 物理 | 固定1/120秒，每绘制回调最多4步；粒子不互撞，复杂度O(N) |
| 冷却 | 常规发射请求至少1.2秒；低动态至少2.4秒；丢脸不重置冷却 |
| 过期与看门狗 | 400ms旧关键点作废；单帧4秒未完成则停机并显式报错 |
| 隐私 | 不请求麦克风；不录制、不上传帧、不保存个人系数；停用/离开释放媒体轨道 |

模型与WASM的冷启动远大于业务JS，不能用“几十KB主包”冒充全部成本。授权成功前，Worker、模型和WASM请求数为零。模型/WASM本身约15MB未压缩；真实网络压缩与缓存数据见 [Part 2](./assignment/part-2-ar-prototype.md)。

## 验证口径

- 单元测试覆盖低cheek、低jaw、张嘴时smile下降、说话脉冲、打哈欠、短暂丢脸、10/30Hz等价性、碰撞与资源上限。
- 浏览器**合成系数 fixture**只替换推理输出，仍走真实摄像头模式的校准、状态机、天气切换和渲染链路；不是只点“演示”按钮。
- 另有真实WASM模型＋模拟采集设备，以及真实模型＋授权图像的本地Canvas视频流测试。
- 可见性检查区分透明像素覆盖与合成到亮/暗背景后的对比度；截图本身不等同于“写实程度已量化”。
- 性能采样明确设备、视口、DPR、时长、峰值粒子及滚动p95，不把桌面移动视口模拟说成手机真机。
- GitHub Actions 对主分支执行干净依赖安装、单元测试、文档校验、构建和浏览器测试，再部署 Pages。

证据摘要见 [assignment/evidence/](./assignment/evidence/)，已知问题和下一轮验收见 [CONTINUE.md](./CONTINUE.md)。

## 不能夸大的边界

1. “大笑”是可见面部动作的代理，不识别真实情绪或笑声。持续带笑说话可能与张嘴大笑不可区分；灵敏度越高越需要注意误触。
2. 碰撞是**2D屏幕空间椭圆**，包含平移和面内转动，不具备3D遮挡、侧脸重建或头发网格。
3. 自动化回归通过不等于真人准确率达标。新版仍需用户实测、iOS/Android真机、弱光、侧脸与长时间温升验收。
4. 技术允许公开展示不代表所有品牌、文化或商业用途都已获得审核。题目图片的本次公开再分发由提交者明确确认；本项目不主张图片作者身份。
